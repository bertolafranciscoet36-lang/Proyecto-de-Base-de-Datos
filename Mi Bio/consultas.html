Consultas en MySQL

Las consultas son las instrucciones que le mandamos a la base de datos para pedirle información. Con SQL podemos elegir qué datos queremos ver, filtrarlos según una condición y unir tablas relacionadas, todo en una sola sentencia.

SELECT y WHERE
SELECT nombre_usuario, correo_electronico FROM usuarios WHERE id_usuario = 101;

SELECT elige las columnas que queremos ver y WHERE filtra los registros que cumplen la condición.

JOIN
SELECT c.nombre, v.fecha, v.total FROM clientes c INNER JOIN ventas v ON v.id_cliente = c.id_cliente;

JOIN une dos tablas usando una columna en común, en este caso el id del cliente.

En el infográfico: al ingresar las credenciales en el formulario, MySQL busca una coincidencia exacta de usuario y contraseña en la base de datos. Si la encuentra, permite el inicio de sesión, y si no, deniega el acceso.
