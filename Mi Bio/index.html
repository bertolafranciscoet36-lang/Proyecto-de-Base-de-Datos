My Sql Workbench

MySQL es un sistema de gestión de bases de datos relacionales de código abierto, propiedad de Oracle. Destaca por ser rápido, seguro, fácil de usar y altamente escalable. Organiza la información en tablas conectadas mediante SQL (Structured Query Language) y es el motor detrás de la mayoría de los sitios web de internet, potenciando desde blogs en WordPress hasta plataformas masivas como Facebook y Twitter.

Código abierto

MySQL se puede descargar y usar gratis, y su código está disponible para que cualquiera lo revise y lo mejore. Detrás hay una comunidad enorme de desarrolladores que aporta documentación, correcciones y respuestas a dudas.

Relacional

Los datos se guardan en tablas de filas y columnas conectadas entre sí mediante claves. Por ejemplo, una tabla de clientes se relaciona con una de compras usando el id del cliente, y así no se repite información.

Multiplataforma

Funciona en Windows, macOS y Linux, así que se puede instalar en casi cualquier computadora. Además se conecta con lenguajes como Python, PHP y Java, para que una página o aplicación guarde y lea sus datos desde MySQL.
